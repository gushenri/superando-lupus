## ✨ Sobre o projeto

O **Superando o Lúpus** é um site em desenvolvimento que reúne conteúdos educativos, informações sobre direitos, iniciativas e caminhos para participação. A proposta é criar um ambiente digital acolhedor, de navegação simples e acessível, voltado a pessoas com lúpus, familiares e à comunidade.

> Ninguém precisa enfrentar o lúpus sozinho.

## 🖥️ Prévia do site

![Página inicial do Superando o Lúpus](./screenshots/home.png)

## 🧭 Seções

- **Início:** apresentação do projeto e acesso aos conteúdos principais.
- **Associação:** missão, atuação e formas de participação.
- **Entenda o lúpus:** conteúdos educativos sobre a condição.
- **Direitos:** orientações e informações sobre direitos.
- **Projetos:** iniciativas e ações de conscientização.

> Algumas seções e funcionalidades ainda estão em desenvolvimento.

## 🛠️ Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

## 🚀 Executar localmente

**Pré-requisito:** Node.js instalado.

```bash
# Instalar dependências
npm install

# Iniciar ambiente de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.
